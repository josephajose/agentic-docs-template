# Usage log

One line per agent session, written by `/agent-flow open` (start) and `/agent-flow close` (end). Lets the Architect match session windows against the tool's usage export to attribute usage to slices. Local times. No personal data: only ids, kinds, owners, times and models.

Format: `- <id> | <slice|ops|uat> | <owner ide|bc-…> | open <YYYY-MM-DD HH:MM TZ> | close <YYYY-MM-DD HH:MM TZ or —> | model <name or auto>`
