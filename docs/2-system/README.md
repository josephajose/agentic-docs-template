# 2-system

How software is designed to implement the domain. Kept in sync with [1-domain](../1-domain/README.md).

## Contents

- `architecture/`: high-level system design.
- `features/`: one doc per core feature; start from [_template.md](features/_template.md). Each cites `Implements: 1-domain/...`.
- `contracts/`: interfaces with other systems or packages.
- `technical/`: data, persistence, calc rules, ops notes (no upstream domain cite required).
- `decisions/`: architecture decision records ([_template.md](decisions/_template.md)).
